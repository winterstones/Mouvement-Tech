01. Le Constat de Défaillance

90% des développeurs utilisent l'IA.
Combien font de la vraie ingénierie ?

1

L'Illusion du Déclaratif

Les auto-évaluations et questionnaires RH sont biaisés : tout le monde prétend être "expert IA", mais les CTO n'ont aucune visibilité factuelle sur la maturité réelle.

2

Le Piège du "Vibe Coding"

Génération massive de code sans mémoire projet, sans harnais et sans tests, provoquant jusqu'à 80% de reprise humaine après coup et une dette technique explosive.

💡 Le problème : Générer du code ne fait pas de vous un ingénieur augmenté. Piloter l'IA avec rigueur, oui.
02. La Solution Déterministe

Mouvement-Tech : Mesurer ce qui est fait, pas ce qui est dit.

Une évaluation 100% empirique, sans questionnaire, basée exclusivement sur les traces vérifiables dans Git et gouvernée par le référentiel officiel AIDD.

1. Taille des Livrables

Amplitude fonctionnelle (, M, L, XL$) par périmètre multi-fichiers et impact sémantique.

2. Harness & Mémoire

Context engineering (AGENTS.md), règles, skills versionnés et boucles fermées CI.

3. Cadrage & Délégation

Mesure du moment d'intervention : zéro reprise après coup vs corrections massives.

4. Flux Parallèles

Orchestration simultanée de plusieurs chantiers menés de front (branches, Git Worktrees).

⚖️ Règle d'Or AIDD : Règle stricte du MIN (votre niveau global est celui de votre axe le plus faible). Niveau = MIN(T, H, I, P)
03. Innovation Moteur AST & Dette

Distinguer l'Ingénierie Saine du Vibe Coding

Notre analyse syntaxique AST calcule l'indice de maintenabilité, la complexité cyclomatique, les God Functions (>50 lignes) et classifie le code en 4 archétypes :

🛡️ Artisanat Sain (Non-IA) 0% IA · 0% Risque

Code propre, modulaire et testé manuellement. Aucun risque de dette IA.

🚨 Vibe Coding Debt (Alerte) >60% IA · Risque 85%

Génération massive non cadrée, sans harnais, 80% de reprises et complexité non maîtrisée.

⚠️ Dette Legacy Manuelle 0% IA · Dette 60%

Code historique non refactorisé, fonctions géantes créées avant l'ère de l'IA.

🏆 AIDD Certifié (Augmenté) 80% IA · 0% Dette

Excellence opérationnelle : mémoire complète, boucles de validation automatique, zéro reprise.
